# PDF PNG 변환기

PDF 파일을 브라우저에서 긴 변 1080px PNG 파일로 변환하는 웹앱입니다.

## 배포

- GitHub Pages: https://wbmaker2.github.io/pdf-to-png/

## 기능

- PDF 1개를 선택해 각 페이지를 PNG로 변환합니다.
- 출력 PNG는 원본 비율을 유지하고 긴 변을 1080px로 맞춥니다.
- 한 페이지 PDF는 `원본이름-00.png`로 다운로드합니다.
- 여러 페이지 PDF는 `원본이름-png-1080px.zip`으로 다운로드합니다.
- ZIP 내부 파일명은 `원본이름-00.png`, `원본이름-01.png` 형식입니다.
- PDF 파일은 서버로 업로드되지 않고 브라우저 안에서 처리됩니다.
- PDF는 50MB 이하, 최대 50페이지까지 변환할 수 있습니다.

## 파일명 규칙

원본 PDF 이름에서 `.pdf` 확장자를 제거한 뒤 0부터 시작하는 페이지 번호를 붙입니다.
예를 들어 `수업자료.pdf`의 첫 페이지는 `수업자료-00.png`, 두 번째 페이지는
`수업자료-01.png`가 됩니다. 페이지가 100장 이상이면 `000`, `001`처럼 자릿수를
자동으로 늘립니다.

## 개발

```bash
npm install
npm run dev
```

기본 개발 서버는 `http://localhost:5173/`에서 열립니다.

## 검증

```bash
npm test -- --run
npm run lint
npm run build
```

브라우저 검증에서는 1페이지 PDF, 여러 페이지 PDF, PDF가 아닌 파일을 각각 업로드해
PNG/ZIP 다운로드 이름과 모바일 레이아웃을 확인합니다.
